GitHub Pages 배포용 사주풍경 Narrative 2.2

핵심 수정
- 대운의 기본 표시를 '대운수'로 통일했습니다.
- 대운수 4이면 4세, 14세, 24세, 34세...를 기본 시간표로 표시합니다.
- 정밀 교운일은 별도 참고정보로 표시합니다.
- 세는나이 연도 환산도 '만세력 비교용'으로 분리했습니다.
- 한글 명식 입력을 지원합니다.

GitHub Pages
1. 이 폴더의 index.html, THIRD_PARTY_NOTICE.txt, .nojekyll 파일을 GitHub 저장소 최상위에 업로드합니다.
2. GitHub 저장소 Settings > Pages로 이동합니다.
3. Source: Deploy from a branch
4. Branch: main / (root)
5. Save
6. 수 분 뒤 https://사용자이름.github.io/저장소이름/ 형태의 주소가 생성됩니다.
